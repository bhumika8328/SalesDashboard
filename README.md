# 📊 Sales Dashboard

A responsive and interactive **Sales Dashboard** built using **HTML, CSS, JavaScript, and Chart.js**. The dashboard provides a visual overview of sales performance through KPIs, charts, filters, regional analysis, and product performance.

## 🚀 Features

- 📈 **Revenue Trend** — View monthly revenue performance.
- 🌍 **Region-wise Sales** — Analyze sales across different regions.
- 🛍️ **Top Selling Products** — View product sales and order performance.
- 📊 **Sales by Category** — Visualize revenue distribution across categories.
- 🔎 **Interactive Filters** — Filter dashboard data by:
  - Year
  - Region
  - Category
  - Product
- 💰 **Key Performance Indicators**
  - Total Revenue
  - Total Orders
  - Average Order Value
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile screen sizes.
- 🎨 **Modern UI** — Dark-themed dashboard with cards, charts, and responsive layouts.

## 🛠️ Technologies Used

- **HTML5** — Dashboard structure
- **CSS3** — Styling, responsive layout, animations and UI design
- **JavaScript** — Dynamic data handling and interactive filters
- **Chart.js** — Data visualization and charts
- **Google Fonts** — DM Sans and Manrope

The project imports Chart.js and Google Fonts directly in the HTML file.

## 📊 Dashboard Sections

### 1. KPI Cards

The dashboard displays three important business metrics:

- **Total Revenue**
- **Total Orders**
- **Average Order Value**

### 2. Revenue Trend

A line chart displays monthly revenue performance from **January to December**.

### 3. Sales by Region

A doughnut chart shows revenue contribution from:

- South
- North
- East
- West

### 4. Region-wise Sales

A bar chart provides a comparison of sales volume across different geographical regions.

### 5. Top Selling Products

The dashboard displays product-level information including:

- Product name
- Sales
- Orders
- Performance

### 6. Sales by Category

A horizontal bar chart visualizes revenue distribution across product categories such as:

- Electronics
- Fashion
- Home & Living
- Sports
- Books

These dashboard sections and filters are present in the project HTML.

## 🔎 Interactive Filtering

Users can change the dashboard data using four filters:

```text
Year → Region → Category → Product
```

Changing a filter dynamically updates the dashboard metrics and charts using JavaScript.

## 📱 Responsive Design

The dashboard includes responsive layouts for different screen sizes:

- Desktop
- Tablet
- Mobile

CSS media queries adjust the sidebar, filters, KPI cards, charts, and content layout according to the screen width.

## ▶️ How to Run

### Option 1 — Open directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.

### Option 2 — Using VS Code

1. Open the project in **VS Code**.
2. Open `index.html`.
3. Use **Live Server** to launch the dashboard in your browser.

No backend server or database is required for the current version.
